# 安卓手机媒体全量导出

[English](README.md) | [简体中文](README.zh-CN.md)

> 把安卓手机上的照片、视频、微信保存图片、截图、录屏按大分类全量导出到电脑，支持 USB 与无线 ADB 两种连接。

## 这是什么

这不是一个"把文件拷过去"的工具。拷文件的工具搬完字节就算完事，这里要的不是这个。

目标是：一张不多、一张不少、分类正确，而且事后随时可以复核。

这个区别重要，是因为手机往电脑导照片的失败方式都特别具体又特别无聊 —— 日期区间重叠导致重复文件、截图混进相机目录、线碰一下就静默少传一批。这个技能就是围绕这几种失败来做校验的。

## 为什么开源

做这个是因为同一件杂活反复在做 —— 出门前清手机存储、把某场活动的照片归到项目目录、把同事的截图汇到共享盘。每次用不同的工具，每次都会留下一点不太一样的烂摊子。

公司里日常就是拿它干这些：常规的媒体导出和归档。它不挂靠我们任何产品，所以拿出来分享没有什么顾虑。

## 能做什么

- **无线 ADB 优先。** Android 11 及以上，无线调试通常比 USB 更稳，速度一般也更快。没有线会被碰掉，也不用反复重连。
- **两种连接方式。** 能用无线就用无线，USB 作为兜底。
- **增量核对。** 再跑一次导出时，是拿电脑上已有的内容做比对，而不是闭着眼睛重拷一遍。
- **断点续传。** 中途断了，下一次接着跑，不用从头来。
- **分类映射。** 照片、视频、微信保存的图片、截图、录屏各自进各自的目录，映射关系是写下来的，不是靠猜硬编码的。
- **跨 ROM 实测。** 小米 / HyperOS 和原生安卓在目录结构和媒体扫描结果上不一样，两种都覆盖了。

## 环境要求

Windows · Python 3 · adb（Android Platform Tools）已加入 PATH

## 安装

```bash
git clone https://github.com/<你的用户名>/android-media-export.git
```

然后把整个目录放进技能目录：

| 系统 | 路径 |
|---|---|
| Windows | `C:\Users\<你>\.workbuddy\skills\android-media-export\` |
| macOS / Linux | `~/.workbuddy/skills/android-media-export/` |

没有构建步骤，重启对话即生效。

## 怎么用

用大白话说需求就行：

- "把手机照片复制到电脑，按分类整理"
- "导出手机相册，走 Wi-Fi 连的"
- "把手机里的媒体都导出来，截图和相机照片分开"

它会先确定连接方式，然后带核对地跑导出，最后按分类报数字，方便对数。

## 注意与边界

1. **无线调试要开一次。** 安卓需要先在开发者选项里配对一次，之后才能无线连。仓库里写了具体步骤。
2. **分类靠规则判断。** 系统里没有一个字段叫"这是截图"。分类是建立在路径特征和文件名规律上的，规则是写明的，你可以按自己的机器调整。
3. **HEIC 之类的新格式** 原样拷过去。转格式是另一件事，这里不做。
4. **第一次全量导出比较慢。** 这是校验相比单纯拷贝要付的代价。
